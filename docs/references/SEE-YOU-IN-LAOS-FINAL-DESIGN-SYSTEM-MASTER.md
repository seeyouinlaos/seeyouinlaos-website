## 12. PHOTOGRAPHIC CI & PRODUCTION CHAIN
Signature: **HIGH-END TRAVEL EDITORIAL + QUIET LUXURY HOSPITALITY + DOCUMENTARY AUTHENTICITY.**

Production chain (mandatory order): SEMANTIC VERIFICATION → BEST LEGITIMATE SOURCE → PHOTOGRAPHIC MASTER EDIT → ROLE ASSIGNMENT → ART-DIRECTED CROP → RESPONSIVE DERIVATIVE IF REQUIRED → RESIZE → OUTPUT SHARPENING → INSPECTED COMPRESSION → SEMANTIC NAMING → APPROVED DRIVE LOCATION → WEB READY.

Master edit precedes web export and may include exposure, highlight roll-off, shadow recovery, white balance, dodge/burn, colour grading, perspective, restrained retouching, noise/detail treatment, master sharpening.

Required behaviour: controlled highlights · dimensional open shadows · restrained saturation · warm-neutral whites · natural skin · controlled greens/blues · deep elegant burgundy/red · realistic gold · no obvious vignette/filter.
Reject: cheap HDR · influencer presets · synthetic cinematic grading · excessive clarity · crushed blacks · plastic skin · fake depth of field · AI-looking enhancement.

Destination character varies naturally: Bangkok warmer/urban/graphic · Vientiane calm/warm-neutral/heritage-led · Kunming lighter/botanical/slightly cooler · Lijiang clear/textural/mountainous/slightly cooler.

Truth & rights: Owner source preserved, never overwritten. Watermarked, marketplace-preview or rights-unclear imagery = **REFERENCE ONLY — NEVER WEB READY**; watermarks are never removed to manufacture assets. Before upscaling, search for a higher-resolution legitimate original; upscaling must never hallucinate faces, signage, architecture, materials. If insufficient: **LOW RESOLUTION — LIMITED USE**, role downgraded. Photographic derivatives contain no baked-in headlines, dates, slogans or interface typography (genuine photographed signage remains documentary). Website production uses the approved WEB READY derivative and must not re-grade, regenerate, substitute or arbitrarily recrop it.
