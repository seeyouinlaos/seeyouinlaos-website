## Engine observation (not changed, by instruction)
`src/seating.js` answers a refused select with `{ ok:false, error:'taken', ...view }` — the spread view carries its own `ok:true`, so the 409 body reads `ok:true, error:'taken'`. The client now judges a hold by **status + error + the fresh ledger** (`confirmSeat`), never by the body's `ok`. A one-line reorder in the engine (`{ ...view, ok:false, error }`) would make the body truthful; left for the Owner as an engine follow-up.
